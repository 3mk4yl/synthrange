# Overview

SynthRange is a community platform for studying how autonomous security agents behave against observable, owned systems. Its purpose is not to prescribe a single run path, but to provide reusable architecture, target adapters, playbooks, evidence collection, and reporting that others can extend.

## What SynthRange provides

- bounded but tactically autonomous Red and Blue agents;
- reusable playbooks rather than scripted sequences;
- target adapters for applications and operating systems;
- neutral Observer evidence and reproducible run records;
- traffic visibility and policy through an optional proxy;
- outputs suitable for detection engineering, threat research, and defensive improvement.

## Product boundaries

SynthRange is designed for systems the operator owns or is authorized to assess. Scope, authorization, and evidence integrity are operational requirements, not the main product narrative.

## Maturity model

- **Available:** implemented and validated in the reference lab.
- **Prototype:** implemented but incomplete or not deployed by default.
- **Planned:** accepted architecture with implementation still required.
- **Vision:** longer-term direction that may change.
