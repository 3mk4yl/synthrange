# Web Activity Triage

**Role: Blue · Status: Available**

Independent defensive triage of web activity, target telemetry, and health. Blue establishes its own baseline, classifies evidence with confidence, identifies blind spots, and develops detections and recommendations.

Requires `service.health`, `telemetry.container-logs`, Observer, Traffic Proxy, and the shared [Run Evidence Baseline](../../shared/run-evidence-baseline/).

See [`playbook.yaml`](playbook.yaml) for the authoritative contract.
