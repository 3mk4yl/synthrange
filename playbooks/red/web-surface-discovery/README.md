# Web Surface Discovery

**Role: Red · Status: Available**

Autonomous low-impact discovery of an approved web application surface. Red chooses tactics and follows evidence within the run's authority; the playbook does not prescribe routes or commands.

Requires `web.http`, `service.health`, Observer, Traffic Proxy, and the shared [Run Evidence Baseline](../../shared/run-evidence-baseline/).

See [`playbook.yaml`](playbook.yaml) for the authoritative contract.
