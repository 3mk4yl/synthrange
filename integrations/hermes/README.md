# Hermes integration

**Status: Planned**

The reference lab runs Hermes agents on Red and Blue only. Observer, Target, and Traffic Proxy are services or passive environments and do not run Hermes.

Nothing is packaged here yet. Public Hermes integration packages are conditional on the roadmap's hardened-repeat gate: they are considered only after the bounded reference run repeats under hardened controls. See [Next: repeatability before expansion](../../ROADMAP.md#next-repeatability-before-expansion).

This directory therefore documents intent. It does not provide installation guidance or a distributable package.
