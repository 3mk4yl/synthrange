# Support

SynthRange is an open research idea and reference implementation, not a supported product. There is no service level, no guaranteed response time, and no obligation to accept a request.

- Use [GitHub Issues](https://github.com/akinteldev/synthrange/issues) for reproducible bugs, questions about the architecture or contracts, and work proposals you would like reviewed before implementing.
- Use [private security advisories](https://github.com/akinteldev/synthrange/security/advisories/new) for vulnerabilities in SynthRange. Do not report them in a public issue.

Well-scoped issues get the most useful answers. Include the relevant commit, deployment shape, target adapter, playbooks, expected behavior, actual behavior, and sanitized logs. Never post credentials, private certificates, or sensitive run evidence.
